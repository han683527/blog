# 统一响应与异常处理

## Result — 统一响应格式

```java
@Data
public class Result<T> {
    private int code;
    private String message;
    private T data;

    public static <T> Result<T> success(T data) {
        Result<T> r = new Result<>();
        r.code = 200;
        r.message = "success";
        r.data = data;
        return r;
    }

    public static <T> Result<T> error(String message) {
        Result<T> r = new Result<>();
        r.code = 400;
        r.message = message;
        r.data = null;
        return r;
    }

    // 带状态码的 error，配合自定义异常使用
    public static <T> Result<T> error(int code, String message) {
        Result<T> r = new Result<>();
        r.code = code;
        r.message = message;
        r.data = null;
        return r;
    }
}
```

**返回示例：**

```json
// 成功
{ "code": 200, "message": "success", "data": { ... } }

// 失败 - 资源不存在
{ "code": 404, "message": "文章不存在", "data": null }

// 失败 - 没有权限
{ "code": 403, "message": "不能删除别人的文章", "data": null }

// 失败 - 参数错误
{ "code": 400, "message": "邮箱已被注册", "data": null }
```

前端判断 `code` 就能区分不同场景（200/400/403/404），统一处理。

### 泛型方法

```java
public static <T> Result<T> success(T data)
```

`<T>` 声明泛型方法，传入 `Article` 得 `Result<Article>`，传入 `String` 得 `Result<String>`，编译期就知道类型。

## 自定义异常类

把不同的业务错误定义成独立的异常类，和 HTTP 状态码一一对应：

| 异常类 | 状态码 | 场景 |
|---|---|---|
| `BadRequestException` | 400 | 参数错误、邮箱已注册、密码错误 |
| `NotFoundException` | 404 | 文章/评论/用户不存在 |
| `ForbiddenException` | 403 | 修改/删除别人的资源 |

```java
// 存放在 common 模块的 exception 包下
public class NotFoundException extends RuntimeException {
    public NotFoundException(String message) { super(message); }
}

public class ForbiddenException extends RuntimeException {
    public ForbiddenException(String message) { super(message); }
}

public class BadRequestException extends RuntimeException {
    public BadRequestException(String message) { super(message); }
}
```

继承 `RuntimeException`，所以抛异常的方式不变：

```java
// 改前
throw new RuntimeException("文章不存在");
throw new RuntimeException("不能删除别人的文章");

// 改后
throw new NotFoundException("文章不存在");
throw new ForbiddenException("不能删除别人的文章");
```

**为什么不用 RuntimeException 统一处理？** 前端无法区分"参数错误"和"资源不存在"，统一弹 400 提示不准确。

## 全局异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BadRequestException.class)
    public Result<Void> handleBadRequest(BadRequestException e) {
        return Result.error(400, e.getMessage());
    }

    @ExceptionHandler(NotFoundException.class)
    public Result<Void> handleNotFound(NotFoundException e) {
        return Result.error(404, e.getMessage());
    }

    @ExceptionHandler(ForbiddenException.class)
    public Result<Void> handleForbidden(ForbiddenException e) {
        return Result.error(403, e.getMessage());
    }

    @ExceptionHandler(RuntimeException.class)
    public Result<Void> handleException(Exception e) {
        return Result.error(400, e.getMessage());
    }
}
```

- `@RestControllerAdvice` —— 全局拦截所有 Controller 抛出的异常
- 多个 `@ExceptionHandler` 方法，每个处理一种异常
- Spring 根据抛出的异常类型，自动匹配对应的处理方法
- 最后的 `RuntimeException` 兜底，防止没被捕获的异常

### 参数校验异常捕获

```java
@ExceptionHandler(MethodArgumentNotValidException.class)
public Result<Void> handleValidation(MethodArgumentNotValidException e) {
    String message = e.getBindingResult().getFieldError().getDefaultMessage();
    return Result.error(400, message);
}
```

当 `@Valid` 校验失败时，Spring 抛出 `MethodArgumentNotValidException`。异常里包含校验结果 `BindingResult`，通过 `getFieldError().getDefaultMessage()` 拿到注解上定义的 `message`：

```java
@NotBlank(message = "标题不能为空")  // ← 这里定义的 message
private String title;
```

校验失败时前端收到：
```json
{ "code": 400, "message": "标题不能为空", "data": null }
```

**不加这个处理：** Spring 返回默认错误结构（字段名、错误类型等冗长信息），不是 `Result` 格式，前端无法统一处理。

### 完整的 GlobalExceptionHandler

```java
@ExceptionHandler(MethodArgumentNotValidException.class)  // 参数校验
@ExceptionHandler(BadRequestException.class)               // 业务参数错误
@ExceptionHandler(NotFoundException.class)                 // 资源不存在
@ExceptionHandler(ForbiddenException.class)                // 没有权限
@ExceptionHandler(RuntimeException.class)                  // 兜底
```

### 执行流程

```
Controller 方法抛出异常
        ↓
@RestControllerAdvice 拦截
        ↓
匹配异常类型 → MethodArgumentNotValidException → code:400（字段校验失败）
                BadRequestException             → code:400
                NotFoundException               → code:404
                ForbiddenException              → code:403
                RuntimeException                → code:400（兜底）
```

不用全局异常处理的话，每个方法都要 try-catch：

```java
// ❌ 没有全局异常处理
try {
    articleService.delete(id);
    return Result.success("删除成功");
} catch (Exception e) {
    return Result.error(400, e.getMessage());
}

// ✅ 有全局异常处理，Controller 只管正常流程
articleService.delete(id);
return Result.success("删除成功");
```

### 执行流程

```
Controller 方法抛出异常
        ↓
@RestControllerAdvice 拦截
        ↓
匹配异常类型 → BadRequestException → 返回 code:400
                NotFoundException   → 返回 code:404
                ForbiddenException  → 返回 code:403
                RuntimeException    → 返回 code:400（兜底）
```
