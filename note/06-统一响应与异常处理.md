# 统一响应与异常处理

## Result — 统一响应格式

```java
@Data
public class Result<T> {
    private int code;
    private String message;
    private T data;

    public static <T> Result<T> success(T data) {
        Result<T> r = new Result<>();
        r.code = 200;
        r.message = "success";
        r.data = data;
        return r;
    }

    public static <T> Result<T> error(String message) {
        Result<T> r = new Result<>();
        r.code = 400;
        r.message = message;
        r.data = null;
        return r;
    }
}
```

**返回示例：**

```json
// 成功
{ "code": 200, "message": "success", "data": { ... } }

// 失败
{ "code": 400, "message": "文章不存在", "data": null }
```

前端只需判断 `code`，统一处理成功/失败。

### 泛型方法

```java
public static <T> Result<T> success(T data)
```

`<T>` 声明泛型方法，传入 `Article` 得 `Result<Article>`，传入 `String` 得 `Result<String>`，编译期就知道类型。

## 全局异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(RuntimeException.class)
    public Result<Void> handleException(Exception e) {
        return Result.error(e.getMessage());
    }
}
```

- `@RestControllerAdvice` —— 全局拦截所有 Controller 抛出的异常
- `@ExceptionHandler(RuntimeException.class)` —— 捕获 RuntimeException 及其子类
- 捕获后返回 `Result.error()`，前端拿到统一 JSON

不用全局异常处理的话，每个方法都要 try-catch：

```java
// ❌ 没有全局异常处理
try {
    articleService.delete(id);
    return Result.success("删除成功");
} catch (Exception e) {
    return Result.error(e.getMessage());
}

// ✅ 有全局异常处理，Controller 只管正常流程
articleService.delete(id);
return Result.success("删除成功");
```

## 自定义业务异常

目前所有业务异常都用 `RuntimeException`，传入不同 message 区分。后续可以根据不同场景定义子类，区分 HTTP 状态码：

```java
public class NotFoundException extends RuntimeException {
    public NotFoundException(String message) { super(message); }
}

public class ForbiddenException extends RuntimeException {
    public ForbiddenException(String message) { super(message); }
}
```

在异常处理器里针对不同异常返回不同状态码：

```java
@ExceptionHandler(NotFoundException.class)
public Result<Void> handleNotFound(NotFoundException e) {
    return Result.error(e.getMessage()); // 返回 404
}
```
