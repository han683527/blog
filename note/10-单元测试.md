# 单元测试

## 什么是单元测试

用代码测试代码，验证某个方法单独拿出来跑时行为对不对。每次改完代码跑一遍测试，确保没把以前好的功能改坏。

## JUnit 5 + Spring Boot Test

Spring Boot 的 `spring-boot-starter-test` 自带 JUnit 5 + Mockito + AssertJ，不需要额外加依赖。

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>
```

## 测试结构

测试放在 `src/test/java/` 下，和业务代码包路径一致：

```
user/src/test/java/org/example/blog/service/
├── ArticleServiceTest.java
├── CommentServiceTest.java
└── UserServiceTest.java
```

类名规范：`{被测试类名}Test.java`

## 常用注解

| 注解 | 作用 |
|---|---|
| `@SpringBootTest` | 启动 Spring 容器，用真实数据库 |
| `@Transactional` | 测试完自动回滚，不影响数据库 |
| `@Test` | 标记这是一个测试方法 |

## 断言方法

```java
import static org.junit.jupiter.api.Assertions.*;

assertNotNull(obj);                    // 不为 null
assertEquals("期待值", actual);        // 相等
assertThrows(异常类.class, () -> { }); // 应该抛指定异常
assertTrue(条件);                       // 条件为 true
assertFalse(条件);                      // 条件为 false
```

## 示例

```java
@SpringBootTest
@Transactional
class ArticleServiceTest {

    @Autowired
    private ArticleService articleService;

    // 测试"查不到"的情况
    @Test
    void testGetArticleById_NotFound() {
        assertThrows(NotFoundException.class,
                () -> articleService.getArticleById(999L));
    }

    // 测试"正常查到"的情况
    @Test
    void testGetArticleById_Success() {
        articleService.createArticle(1L, "测试标题", "测试内容");

        LambdaQueryWrapper<Article> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(Article::getTitle, "测试标题");
        Article created = articleService.getOne(wrapper);

        ArticleResponse article = articleService.getArticleById(created.getId());
        assertNotNull(article);
        assertEquals("测试标题", article.getTitle());
    }
}
```

## 测试原则

- 一个测试方法测**一个**场景（正常 / 查不到 / 没权限）
- 方法名用 `test{方法名}_{场景}`，一看就知道测什么
- 测试之间互不依赖，每个方法独立运行
- `@Transactional` 保证测试数据不影响数据库

## 运行测试

```bash
mvn test                         # 跑所有模块的测试
mvn test -pl user                # 只跑 user 模块
mvn test -Dtest=ArticleServiceTest  # 只跑某个测试类
```
