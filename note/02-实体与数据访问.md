# 实体与数据访问

## Entity（实体层）

实体类和数据库表一一对应。

```java
@Data
@TableName("Article")
public class Article {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String title;
    private String content;
    private Long authorId;
    private LocalDateTime createTime;
}
```

### 常用注解

| 注解 | 作用 |
|---|---|
| `@Data` | Lombok —— 生成 getter/setter/toString/equals/hashCode |
| `@TableName("表名")` | 类名和表名不一致时指定 |
| `@TableId(type = IdType.AUTO)` | 主键，AUTO = 数据库自增 |
| `@TableField(exist = false)` | 非数据库字段（比如一个临时计算字段） |
| `@TableLogic` | 逻辑删除字段 |

### 驼峰映射

```yaml
mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true
```

Entity 的 `createTime` → 数据库 `create_time`，自动映射。

## Mapper（数据访问层）

```java
public interface ArticleMapper extends BaseMapper<Article> { }
```

### BaseMapper 自带方法

| 方法 | 对应 SQL |
|---|---|
| `insert(entity)` | `INSERT INTO 表 VALUES ...` |
| `deleteById(id)` | `DELETE WHERE id = ?` |
| `updateById(entity)` | `UPDATE 表 SET ... WHERE id = ?` |
| `selectById(id)` | `SELECT * FROM 表 WHERE id = ?` |
| `selectList(wrapper)` | `SELECT * FROM 表 WHERE 条件` |
| `selectCount(wrapper)` | `SELECT COUNT(*) FROM 表 WHERE 条件` |

空接口就能工作，MyBatis-Plus 通过动态代理在运行时生成实现。

## MyBatis-Plus 分页插件

```java
@Configuration
public class MybatisPlusConfig {
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}
```

**没有这个插件**，`this.page(new Page<>(1, 10))` 不会生成 `LIMIT` / `SELECT COUNT(*)`，而是查出全部数据。

## IService / ServiceImpl

```java
public interface ArticleService extends IService<Article> { }
public class ArticleServiceImpl extends ServiceImpl<ArticleMapper, Article>
        implements ArticleService { }
```

ServiceImpl 内部持有 Mapper 对象，所以可以直接：

```java
this.save(article);        // 新增
this.removeById(id);       // 删除
this.updateById(article);  // 更新
this.getById(id);          // 查询单个
this.list(wrapper);        // 查询列表
this.page(page, wrapper);  // 分页
this.count(wrapper);       // 统计总数
this.getOptById(id);       // 查单个，返回 Optional
```
