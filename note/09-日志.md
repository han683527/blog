# 日志

## SLF4J + Logback

Spring Boot 自带 SLF4J（接口） + Logback（实现），**不需要加依赖**。

## 使用方式

### 方式一：Lombok @Slf4j（推荐）

```java
@Slf4j
@Service
public class ArticleServiceImpl extends ServiceImpl<ArticleMapper, Article> implements ArticleService {
    
    public void deleteArticleById(Long id) {
        log.info("用户 {} 删除文章 {}", UserContext.get(), id);
    }
}
```

### 方式二：手动声明（不用 Lombok）

```java
private static final Logger log = LoggerFactory.getLogger(Xxx.class);
```

## 日志级别

| 级别 | 用法 | 示例 |
|---|---|---|
| `info` | 用户做了什么操作 | 创建文章、删除评论 |
| `warn` | 不该发生的事，但系统没挂 | 权限不足、资源不存在 |
| `error` | 意料之外的异常，需要排查 | 全局异常兜底 |

## 在哪加日志

| 层 | 位置 | 级别 |
|---|---|---|
| Service | 创建/删除/修改操作 | info |
| Service | 权限校验失败 | warn |
| Service | 资源不存在 | warn |
| GlobalExceptionHandler | 兜底异常 | error |

### 示例

```java
// Service — 正常操作
log.info("用户 {} 创建文章: {}", userId, title);
log.info("用户 {} 删除文章 {}", userId, id);

// Service — 警告
log.warn("用户 {} 试图删除别人的文章 {}", userId, id);
log.warn("文章 {} 不存在", id);

// GlobalExceptionHandler — 错误
log.error("未捕获异常", e);  // 传 e 才能看到堆栈
```

**注意：** `log.error("消息", e)` 要传异常对象，否则看不到堆栈信息。不要只写 `e.getMessage()`。
